# Unified phased implementation

## Policy and overlap decisions

V6 defines the full product backlog; V7's simpler source-aware UX governs presentation. Reuse all useful current implementations. Do not add menu items for absent functionality or replace the stack. Keep the three meaningful tutor-hint gate because V7 explicitly preserves the current pedagogical guard. Keep hosting Free and actual payments disabled, consistent with the user's instructions. Pricing can remain illustrative with server-decided entitlements.

Existing account/class isolation, immutable issued assessments, canonical source proofs and credit reservation must survive every phase. New animations must support a task and respect reduced motion. Deterministic math verification is labeled with its actual supported scope. No fabricated pilot, parent consent, merchant transaction, production durability or native-device success.
