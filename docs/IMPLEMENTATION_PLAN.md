# Unified V6 + V7 implementation plan

The authoritative detailed plan is [docs/v7/IMPLEMENTATION_PLAN.md](v7/IMPLEMENTATION_PLAN.md). Progress and acceptance evidence live in [docs/v7/CHECKLIST.md](v7/CHECKLIST.md). V6 is the complete capability backlog; V7 determines progressive disclosure, reuse and evidence-based implementation.

Sequence: audit and baseline → security/credits/data integrity → simpler accessible shells → reliable source workflows and AI evaluation → teacher assessment workflows → operations/recovery and learning evidence → responsive/regression/provider acceptance → verified release/evidence → final competition submission 4.

Each phase must record implemented files, focused tests, actual outcomes, remaining limitations and rollback implications. Tests with intercepted providers are labeled as such. No phase is accepted on screenshots alone, and no production or student-outcome claim follows from mock data.
